# Conformance (golden replays)

Language-neutral fixtures that pin down engine behaviour. The Python engine is
the reference; the future Rust port must reproduce every replay exactly.

Planned shape of one replay (format to be fixed in Week 6, with an ADR):

- engine/spec version
- game config (players, layout options)
- seed
- the full ordered action list, including every trade offer and response
- the expected state hash after each action (or at checkpoints)

Replays are generated by tooling, never edited by hand.
